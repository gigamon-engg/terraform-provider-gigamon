# gigamon_app_viz (Resource)

**App Viz** provides real-time visibility into application traffic flowing through a monitoring session by sampling packets and exporting telemetry to a configured monitor endpoint.

Use `mgmt_interface` to select the network path (internal or external) that App Viz uses to reach its export target. The `exporter_config.monitor.timeout` controls how long the export process waits before giving up.

```terraform
# Minimal typed App Viz example.
# This example uses an existing monitoring session that is imported.

    gigamon = {
      source = "local/gigamon/gigamon"
    }
  }
}

  fm_address  = "10.114.50.20"
  skip_verify = true

}

# Store your existing monitoring session ID locally
# Format: monitoringSession::<platform>::<uuid>
locals {
  monitoring_session_id = "monitoringSession::vmware::0ddfdd2d-2a27-4abc-ae39-3432601bcd53"
}

  monitoring_session_id = local.monitoring_session_id

  alias         = "app_viz1"
  description   = ""
  action        = true
  mgmt_interface = "internal"

  exporter_config = {
    monitor = {
      timeout = 300
    }
  }
}
```
